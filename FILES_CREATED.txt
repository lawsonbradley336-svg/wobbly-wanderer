SUMMARY
=======
Built a complete UK Pub Crawl Generator web app with React, Next.js, TypeScript, and Tailwind CSS. 
Features pub crawl generation, route optimization, 30+ challenges, and a beautiful dark UI.

GETTING STARTED (5 MINUTES)
===========================

Step 1: Install Dependencies
$ npm install

Step 2: Run Development Server
$ npm run dev

Step 3: Open in Browser
→ http://localhost:3000

Step 4: Generate Your First Crawl
✓ Enter city: London (or Manchester, Bristol, Bath, Birmingham)
✓ Select number of pubs: 4
✓ Choose walking radius: 20 minutes
✓ Pick a vibe: Random
✓ Click "Generate Crawl"

Step 5: Explore Features
• View pubs in List tab
• See route on Map tab
• Complete Challenges in Challenges tab
• Save your crawl automatically
