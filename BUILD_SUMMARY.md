## 🚀 Getting Started

### Quick Start (5 minutes)

```bash
# 1. Install dependencies
npm install

# 2. Run development server
npm run dev

# 3. Open browser
# Visit http://localhost:3000
```

### First Crawl

1. Enter a city: **London**, **Manchester**, **Bristol**, **Bath**, or **Birmingham**
2. Select number of pubs: **4**
3. Choose radius: **20 minutes**
4. Pick vibe: **Random**
5. Click **Generate Crawl**

### Explore Features

- View pubs in **List** tab
- See route in **Map** tab
- Complete **Challenges**
- Check **Saved Crawls**
- Toggle **Sober Mode**
